# primitive-db

Консольное приложение-имитация примитивной базы данных.


## Управление проектом: uv

Проект полностью управляется инструментом `uv`. Это подтверждается наличием файла `uv.lock` в корне проекта — он фиксирует точные версии всех зависимостей для воспроизводимой сборки.

### Артефакты uv в проекте

| Артефакт | Назначение |

| `uv.lock` | Фиксация версий зависимостей (главный маркер инициализации через uv). |
| `.venv` | Изолированное виртуальное окружение, созданное `uv`. |
| `pyproject.toml` | Конфигурация проекта и точки входа CLI. |

## Управление таблицами

-src/primitive_db/ — исходный код пакета.
-main.py — точка входа CLI (main()), игровой цикл и обработка ввода.
-engine.py — логика команд, валидация типов, работа с метаданными.
-pyproject.toml — конфигурация сборки и метаданные.
-Точка входа CLI: primitive_db.main:main.
-Настройка where = ["src"] обеспечивает корректную установку пакета без префикса src.
-db_meta — файл с сохранёнными метаданными таблиц (JSON).
-README.md — текущая документация.

### Доступные команды

- `create_table <имя_таблицы> <столбец:тип> ...` — создать таблицу. Автоматически добавляется столбец `ID:int`.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `list_tables` — показать список таблиц.
- `help` — справка.
- `exit` — выход.

Поддерживаемые типы: `int`, `str`, `bool`.

### Синхронизация зависимостей (использует uv.lock)
uv sync

### Сборка пакета
uv build

### Установка и запуск
uv pip install dist/primitive_db-*.whl

Точка входа CLI доступна через uv:
uv run database

Вы увидите приглашение к вводу:
>>> Введите команду:

## CRUD-операции

Примитивная СУБД поддерживает полный цикл CRUD через SQL-подобный интерфейс.

### Создание и управление таблицами

- `create_table <name> <col:type> ...` — создать таблицу. Автоматически добавляется колонка `ID:int`.
- drop_table <name> — удалить таблицу.
- list_tables — показать список всех таблиц.
- info <name> — показать структуру и количество записей в таблице.
- insert into <table> values (...) — добавить запись. Значения указываются в порядке колонок (ID подставляется автоматически).
- select from <table> [where <condition>] — выбрать записи. Поддерживается фильтрация по условию.
- update <table> set <col>=<val> [, ...] where <condition>
- delete from <table> where <condition>
